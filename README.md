# Ekaaya International School — Admissions Website

Landing pages for Ekaaya International School, Vadodara (Pre-K to Grade 4). Stack: TanStack Start, React 19, TypeScript, Vite, and Tailwind CSS.

## Pages

- `/` — admissions landing page
- `/early-years` — early years
- `/tour` — book a campus visit
- `/thank-you` — enquiry confirmation

## Run locally

This repo uses [Bun](https://bun.sh) (`bun.lock`).

```sh
bun install
bun run dev -- --host 0.0.0.0 --port 43127
```

Open http://localhost:43127. Supabase settings for local development are in `.env`.
